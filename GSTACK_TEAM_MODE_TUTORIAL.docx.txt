Welcome to the Gstack Team Mode Tutorial!

This document teaches your team how to use gstack team mode to collaborate on
any project using five AI specialists (CEO, PM, Engineer, QA, DevOps).

The tutorial uses a minimal project (hello_world.py) to teach the concepts, then
scales to your real projects.

**Time Investment:** 11 hours (can be compressed to 6-8 hours with parallelization)

================================================================================
2. WHAT IS GSTACK TEAM MODE?
================================================================================

Gstack is an AI-powered workflow tool that runs multi-perspective reviews of
your projects. Instead of one person reviewing everything, you get input from
five specialized AI roles:

**The Five Perspectives:**

1. **AI CEO** (/plan-ceo-review)
   - Validates strategy and scope
   - Challenges assumptions and premises
   - Identifies risks and opportunities
   - Asks: "Is this the right problem to solve?"

2. **AI Project Manager** (/spec)
   - Breaks work into concrete tasks
   - Creates timelines and schedules
   - Identifies dependencies
   - Asks: "How do we break this down?"

3. **AI Software Engineer** (/plan-eng-review)
   - Validates architecture and design
   - Confirms technical feasibility
   - Creates test plans
   - Asks: "Can we actually build this?"

4. **AI QA/QC Engineer** (/qa-only)
   - Tests the entire workflow
   - Finds bugs and edge cases
   - Validates quality
   - Asks: "Does it work?"

5. **AI DevOps Engineer** (/ship)
   - Plans deployment
   - Creates release checklist
   - Plans rollback strategy
   - Asks: "Can we ship it?"

**Key Benefits:**

✓ Multiple perspectives reduce blind spots
✓ All decisions are documented in an audit trail
✓ Async collaboration (no meetings needed)
✓ Scales from solo projects to large teams
✓ Can be applied to any type of project

4. INSTALLATION GUIDE
================================================================================

---
4.1 CLAUDE CODE INSTALLATION
---

**Option A: Using Claude Code CLI (Recommended)**

Step 1: Install Claude Code
   - Visit: https://claude.com/claude-code
   - OR use CLI: `pip install claude-code`

Step 2: Install gstack
   - Navigate to: ~/.claude/skills/
   - Clone gstack:
     `git clone https://github.com/anthropics/gstack.git`
   - Or download: https://github.com/anthropics/gstack/releases

Step 3: Verify Installation
   - Run: `claude --version`
   - Run: `/plan-ceo-review --help`
   - If help appears, you're ready!

Step 4: Test It
   - Create a simple PLAN.md file
   - Run: `/plan-ceo-review PLAN.md`
   - You should see output within 1-2 minutes

**Common Issues:**
- "Command not found": Make sure Claude Code is in your PATH
- "Skills not available": Restart Claude Code after installation
- "Permission denied": Run with sudo or check directory permissions

---
4.2 OPENAI CODEX INSTALLATION
---

**Option A: Using OpenAI API**

Step 1: Get OpenAI API Key
   - Visit: https://platform.openai.com/account/api-keys
   - Create new secret key
   - Copy and save it (you'll need it)

Step 2: Set Environment Variable
   - Mac/Linux:
     `export OPENAI_API_KEY="sk-xxxxx"`
   - Windows PowerShell:
     `$env:OPENAI_API_KEY="sk-xxxxx"`
   - Windows CMD:
     `set OPENAI_API_KEY=sk-xxxxx`

Step 3: Install gstack for Codex
   - Download gstack-codex edition
   - Unzip to your project directory
   - Run: `./setup` (Mac/Linux) or `setup.ps1` (Windows)

Step 4: Verify Installation
   - Run: `codex --version`
   - Run: `./gstack-codex /plan-ceo-review --help`
   - You should see the skill help text

Step 5: Test It
   - Create PLAN.md
   - Run: `./gstack-codex /plan-ceo-review PLAN.md`
   - Wait 1-3 minutes for output

**Pricing Note:**
- Codex usage is billed per token
- Tutorial costs approximately $2-5 USD for all 5 reviews
- Budget conscious? Use Claude Code instead (included in subscription)

4.3 TENCENT WORKBUDDY INSTALLATION (Your Tested Method!)
---

You've confirmed this works! Here's how to do it:

Step 1: Prepare gstack
   - Download gstack from GitHub or your local copy
   - Create a zip file: `gstack.zip` (contains all gstack files)

Step 2: Upload to Workbuddy
   - Open Tencent Workbuddy
   - Go to Skills section
   - Click "Upload Custom Skill"
   - Select `gstack.zip`
   - Wait for upload to complete

Step 3: Configure
   - In Workbuddy Skills settings, enable gstack
   - Restart Workbuddy
   - You should see gstack skills in the skill menu

Step 4: Verify Installation
   - Create PLAN.md in your Workbuddy project
   - Type: `/plan-ceo-review PLAN.md`
   - Run the skill
   - You should see CEO_REVIEW.md generated

Step 5: Test the Full Workflow
   - Run all 5 skills in sequence (or parallel)
   - Watch the review documents get generated
   - Beautiful! You now have all 5 perspectives

**Advantages of Workbuddy:**
✓ Easiest installation (just zip upload)
✓ No API keys needed
✓ All skills work offline
✓ Team can collaborate in same workspace
✓ No additional costs

8. TROUBLESHOOTING
================================================================================

Problem: "Command not found: /plan-ceo-review"
Solution:
  - Verify gstack is installed in ~/.claude/skills/
  - Restart Claude Code or Workbuddy
  - Check that PLAN.md exists in current directory

Problem: "Skill times out after 10 minutes"
Solution:
  - Network is slow; try again
  - For Codex: make sure OPENAI_API_KEY is set
  - Try a simpler PLAN.md (fewer sections)

Problem: "Generated review document is empty or incomplete"
Solution:
  - Skill ran but didn't generate output
  - Check file exists: ls -la *.md
  - Re-run the skill
  - If still empty, check logs for errors

Problem: "Collaborator can't see findings in Conductor"
Solution:
  - Make sure Conductor workspace is created
  - Invite collaborator to workspace
  - Post review documents to Conductor manually
  - Verify they have access permissions

Problem: "Git commits keep failing"
Solution:
  - Check git config: git config --global user.email
  - Make sure you've added files: git add .
  - Try committing with full message: git commit -m "message"

Problem: "Team doesn't understand what each review means"
Solution:
  - Print out Section 7 (The Five Perspectives)
  - Have them read one review at a time
  - Discuss key findings in team meeting
  - Connect findings back to your actual project
